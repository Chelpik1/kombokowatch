# KombokoWatch 🎥

> Это бесплатный и уютный онлайн-кинотеатр для просмотра аниме с личным чиби-путеводителем, нашим маскотом Боку.
У нашего проекта нет цели нажиться на пользователях, вся присутствующая на сайте реклама исключительно для оплаты серверов, не назойлива и вписывается в интерфейс.

## Основные возможности 🪄

* **Каталог и поиск:** интеграция с крупнейшей базой аниме и манги Shikimori и плеером Kodik.
* **Собственный удобный плеер:** свой плеер с приятным интерфейсом, запоминанием таймкодов, выбором озвучек и серий.
* **Совместный просмотр:** синхронный просмотр с друзьями в реальном времени по коду комнаты.
* **PWA поддержка:** возможность установить сайт как приложение на смартфон или ПК.
* **Собственная экосистема:** авторизация через аккаунт Shikimori, списки Shikimori и возможность продолжить просмотр тайтла на другом устройстве с того же места, на котором остановились, а также личный чиби-помощник Боку, которы даст совет и подберет случайное аниме. 

## Технологии⚙️:

* **Фронтенд:** HTML5, CSS3, чистый JavaScript (SPA)
* **Бэкенд:** парсер кодика, WebSockets / сигнальные серверы для Watch Party.
* **Хостинг:** GitHub Pages + собственный домен.

## История проекта📋:

Мне просто захотелось создать сайт, на котором не будет назойливой рекламы в каждом углу и в плеере, чтобы спокойно смотреть аниме на уроках на айфоне. Я вдохновился скриптом от YaNesyTortik, и за две недели, при помощи нейросети, спустя сотни промптов, реализовал этот сайт и полностью доволен результатом. Я уверен что сайт будет расти и развиваться. Надеюсь на вашу поддержку!

## Дисклеймер📍:

KombokoWatch не хранит видеофайлы на своих серверах. Все видеопотоки подтягиваются из открытых сторонних источников. Видеоматериалы на сайте предназначены исключительно для ознакомительного просмотра. Проект создан в развлекательных целях и предоставляет доступ к просмотру по принципу «as is» (как есть).
