# KombokoWatch 🎥

> Добро пожаловать в бесплатный и уютный веб-кинотеатр для просмотра аниме без назойливой рекламы.
Наш проект не пытается нажиться на пользователях, вся реклама исключительно для оплаты серверов, не назойлива и вписывается в интерфейс. 
## Основные возможности 🪄

* **Каталог & Поиск:** интеграция с базой Shikimori и Kodik.
* **Собственный удобный плеер:** свой плеер с приятным интерфейсом, запоминанием таймкодов, выбором озвучек и серий.
* **Совместный просмотр:** синхронный просмотр с друзьями в реальном времени по коду комнаты.
* **PWA поддержка:** возможность установить сайт как приложение на смартфон или ПК.
* **Собственная экосистема:** авторизация через аккаунт Shikimori, списки Shikimori и возможность продолжить просмотр тайтла на другом устройстве с того же места, на котором остановились. 

## Технологии:

* **Фронтенд:** HTML5, CSS3, чистый JavaScript (SPA)
* **Бэкенд:** парсер кодика, WebSockets / сигнальные серверы для Watch Party.
* **Хостинг:** GitHub Pages + собственный домен.

## История проекта📋:

Мне просто захотелось создать сайт, на котором не будет назойливой рекламы в каждом углу и в плеере, чтобы спокойно смотреть аниме на уроках на айфоне. Я вдохновился скриптом от YaNesyTortik, и за две недели, при помощи нейросети, спустя сотни промптов, реализовал этот сайт и полностью доволен результатом. Я уверен что сайт будет расти и развиваться. Надеюсь на вашу поддержку!

## Дисклеймер📍:

KombokoWatch не хранит видеофайлы на своих серверах. Все видеопотоки подтягиваются из открытых сторонних источников. Проект создан в образовательных и некоммерческих целях.
